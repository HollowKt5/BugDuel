# 甲虫小憩 · Windows 桌宠

原生 Windows / WPF 程序。**不使用 Unity，不需要 Unity，也没有整块游戏窗口背景。** 甲虫、食盆和折叠控制按钮各自是无边框透明小窗口，透明区域可以点击下面的桌面和应用，宠物不会抢走键盘焦点。

## 启动

双击 `Build/BeetleDesktop.exe`。

当前电脑已安装所需的 .NET 9 Windows Desktop Runtime。复制到别的 Windows 电脑时，需要这个运行时，并一起复制整个 `Build` 文件夹；不要只复制 exe。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键点食盆 | 添加果冻，饿了会自行寻食 |
| 按住左键拖食盆 | 移动喂食地点 |
| 在甲虫上长按右键 0.35 秒 | 抓起并跟随鼠标，松开落地 |
| 抓住时转滚轮 | 每格旋转 15°，松开保留朝向 |
| 左键点翻倒的甲虫 | 帮助翻正，重新开始翻身计时 |
| 右下角「☰」按钮 | 打开饲育面板 |
| 名字旁的「改名」 | 输入 1–12 个字，回车保存，Esc 取消；支持中文输入 |
| 每只甲虫卡片的「名字：开 / 关」 | 显示或隐藏它在桌面上的名字 |
| 每只甲虫卡片的「名字颜色…」 | 选择常用颜色，或调整红、绿、蓝自定义颜色；保存后生效 |
| 「添一只 / 送回一只」 | 一至两只之间切换 |
| 「友好切磋」 | 手动发起无伤害切磋 |
| 「休息 / 继续」 | 暂停或恢复活动 |
| 「—」 | 收起面板 |
| 「退出」 | 保存并关闭全部桌宠窗口 |

固定正上方俯视，复用原项目的真实甲虫模型与贴图。普通甲虫保留原贴图色；每次新增甲虫独立有 **10% 概率成为彩壳**。彩壳使用项目菜单彩色外壳的原始色带与反射色公式，在原生渲染中复现俯视效果；不是加载 Unity 引擎或执行 Unity Shader。外观只在出生时抽取，随存档保存，重启不会重新抽取。

动作包括散步、发呆、观察、梳理触角、进食、睡眠、抓取挣扎、翻倒求助和切磋。六条腿按实际移动距离交替迈步：支撑脚固定桌面接触点，抬脚后向前落下，膝部和足部关节分别弯曲；转弯会重新落脚，停下后完成落脚而不继续原地踩动。两只靠近时偶尔自动切磋，无死亡或永久伤害；抓起其中一只会立即分开。切磋后有 40 秒休息冷却。

每只甲虫约每 **25–35 分钟活动时间** 翻倒一次，腹部朝上蹬腿，左键点一下便可扶正。两只独立计时；休息暂停计时，抓取、进食、睡眠和切磋中延后触发。翻倒时停止寻食和切磋，抓起再放下也仍需帮助扶正。状态与剩余时间随存档保存，旧存档从约 30 分钟开始。

甲虫和食盆都能拖到主显示器的整个屏幕，包括任务栏区域，中心允许稍微越出边缘约24个逻辑像素；放下和重启后保留边缘位置。面板仍放在工作区内。甲虫自主移动时会避开食盆，进食停在盆沿外侧；把甲虫放到盆上或把盆拖到甲虫下面时，会将落地甲虫让到盆外。默认只有一只，面板默认收起。不会添加开机启动项。

甲虫会在日常动作中自主选择「静止」状态，原地停留3分钟后自己恢复活动，剩余时间随存档保存。此状态没有控制按钮，添食或发起切磋都不会打断，也不会在期间自动翻倒。只有抓起会打断，放下并站稳后重新选择动作，仍有可能再次选到静止；全局休息会暂停计时。翻身挣扎使用固定于身体的腿根，上段随身体整体翻转，膝部和足部独立弯曲。

存档独立保存到 `%LOCALAPPDATA%/BeetleDesktop/pets.json`，约每 15 秒和退出时保存，并保留 `.bak` 备份。不会读写原游戏存档。发生启动异常时查看同目录下的 `errors.log`。

## 隔离与构建

本目录可整体搬走，不依赖 BugDuel 或 Unity 工程。模型经过独立 FBX 解析器转成原生网格数据，保留原始 22 个部件、法线、UV 和纹理；身体动作由 WPF 3D 变换驱动，腿部使用三段关节蒙皮与落脚 IK。只有主动打开的改名对话框接收键盘焦点，桌宠窗口保持不抢焦点。

使用 .NET 9 SDK 构建，不需要第三方 NuGet 包：

```powershell
.\Build.ps1
```

源码入口：`Program.cs`，桌面交互：`PetDesktop.cs`，原生窗口：`Platform/`，模型与动画：`Model/`，生活与切磋：`Simulation/`。

## 验证

```powershell
.\Tests\Run-Tests.ps1
dotnet build .\Tests\Gait\GaitChecks.csproj --configfile .\NuGet.Config
dotnet run --project .\Tests\Gait\GaitChecks.csproj --no-build
.\Build\BeetleDesktop.exe --self-test
```

33 项纯 .NET 行为测试覆盖数量限制、寻食、空盆、抓取与切磋互斥、自动/手动切磋、冷却、暂停、长时间边界、确定性、存档恢复、10% 彩壳概率、旧档兼容、实物接触距离、沿朝向移动、不同桌面尺度下的走速、缓转与停顿、起停速度、落地朝向、Unicode 改名、独立翻身计时与帮助扶正。

腿部检查另行运行 2400 帧，覆盖散步、寻食、曲线、原地转向及高速移动，验证至少三足支撑、支撑脚不滑动、关节长度保持，以及停止后六足落地且不继续空踩。

`--self-test` 创建隔离状态并自动退出，检查真实窗口透明配置、原生窗口透明角落点击穿透、可见区域命中、可见/透明像素、长按阈值、拖动、正反向及精细滚轮增量、释放滚轮钩子、改名、扶正和喂食；输出到 `Artifacts/`。图片是程序自己的 WPF 渲染输出，保留 PNG alpha 通道，不是整张桌面截图。测试图片固定各展示一只原色和彩壳，用于对照，不改变正式领养概率。`--qa` 使用临时状态供手工测试，不保存到正式存档。隔离测试的错误日志也在 `Artifacts/`。
